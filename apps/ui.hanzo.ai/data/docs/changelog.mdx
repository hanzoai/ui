Releases are cut by bumping the package version on `main`; each entry below is
the subject of the commit that did.

## 8.27

| Version | Change |
| --- | --- |
| 8.27.10 | Port forty-one components onto the gui backend. |
| 8.27.9 | A grid gap named as a token was always 12px. `gap="$4"` on a grid reads `var(--space-4)` now, so the ladder in the document answers and a density change moves every grid. |
| 8.27.8 | Render the docs for every module from the package itself. This site's catalog reads the barrels, quotes each module's types and renders its examples beside their source. |
| 8.27.7 | Box keeps table parts on their table display values. |
| 8.27.6 | Box carries transition and text-overflow as style on the tag path. |
| 8.27.4 | Parts, Backdrop and Persona; a backdrop painted behind the conversation. |
| 8.27.3 | Ring the whole composer, not the field inside it. |
| 8.27.2 | State a version once; take the brand marks from a brand set; give every dependency one version; supply the web SVG peer and derive both node entries; make the legal entity a value the site states. |
| 8.27.1 | The model picker takes its own width. |
