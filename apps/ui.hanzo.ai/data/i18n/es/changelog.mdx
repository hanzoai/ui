Las versiones se cortan subiendo la versión del paquete en `main`; cada entrada
de abajo es el asunto del commit que lo hizo.

## 8.27

| Versión | Cambio |
| --- | --- |
| 8.27.10 | Pasa cuarenta y un componentes al backend de gui. |
| 8.27.9 | Un gap de cuadrícula nombrado como token valía siempre 12px. `gap="$4"` en una cuadrícula lee ahora `var(--space-4)`, así que la escala del documento responde y un cambio de densidad mueve cada cuadrícula. |
| 8.27.8 | Renderiza la documentación de cada módulo desde el propio paquete. El catálogo de este sitio lee los barrels, cita los tipos de cada módulo y pinta sus ejemplos al lado del código. |
| 8.27.7 | Box deja las partes de una tabla en sus valores de display de tabla. |
| 8.27.6 | Box lleva transition y text-overflow como estilo en el camino de la etiqueta. |
| 8.27.4 | Parts, Backdrop y Persona; un backdrop pintado detrás de la conversación. |
| 8.27.3 | El anillo rodea el compositor entero, no el campo de dentro. |
| 8.27.2 | Declara la versión una sola vez; toma los signos de un conjunto de marcas; dale a cada dependencia una sola versión; aporta el peer SVG de web y deriva las dos entradas de node; convierte la entidad legal en un valor que el sitio declara. |
| 8.27.1 | El selector de modelo toma su propio ancho. |
