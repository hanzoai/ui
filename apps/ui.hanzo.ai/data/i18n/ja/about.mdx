{brand.name} は {brand.org} のコンポーネントライブラリです。一つの基盤の上の、一つのパッケージです。その基盤があるから、一つのインポートが Web でも、電話でも、デスクトップのウィンドウでも動きます。

## 中身

| パッケージ | 担うもの |
| --- | --- |
| [@hanzo/gui](https://gui.hanzo.ai) | スタイルエンジン。スタイルは props で、Web ではアトミック CSS に、電話ではネイティブのスタイルにコンパイルされる。各プリミティブの振る舞い、フォーカス、ポータル、キーボードもここにある。 |
| `@hanzo/design` | トークン。モノクロームのパレット、タイプのランプ、間隔、角丸、高さ、動き、そしてすべてのランプが掛ける三つのノブ。 |
| `@hanzo/font` | Zen と Zen Mono。自分で配信し、SIL Open Font License の下にある。 |
| `@hanzo/appearance` | その人自身の読み方。文字の大きさ、密度、アクセントを保存して適用する。 |

コンポーネントは、この四つを土台にした独自の実装です。下に Radix も、Tailwind も、class-variance-authority も、レジストリもありません。見た目の実体は素の CSS カスタムプロパティで、スタイルシートはパッケージを公開するときに、すべてのコンポーネントを描画して作ります。
