---
title: 変更履歴
description: 各リリースが変えたこと。それを公開したコミットから。
---

リリースは、`main` でパッケージのバージョンを上げて切ります。下の各項目は、それをしたコミットの題です。

## 8.27

| バージョン | 変更 |
| --- | --- |
| 8.27.10 | 四十一のコンポーネントを、gui のバックエンドへ載せる。 |
| 8.27.9 | トークンとして書いたグリッドの gap は、いつも 12px だった。グリッドの `gap="$4"` はいま `var(--space-4)` を読む。文書の中の階段が応え、密度を変えるとすべてのグリッドが動く。 |
| 8.27.8 | 各モジュールのドキュメントを、パッケージ自身から描く。このサイトのカタログはバレルを読み、各モジュールの型を引き、例をソースの横に描く。 |
| 8.27.7 | Box は、テーブルの部品をテーブル用の display の値のまま保つ。 |
| 8.27.6 | Box は、タグの経路で transition と text-overflow をスタイルとして運ぶ。 |
| 8.27.4 | Parts、Backdrop、Persona。会話の背後に塗る背景。 |
| 8.27.3 | リングは内側のフィールドではなく、コンポーザー全体にかける。 |
| 8.27.2 | バージョンは一度だけ書く。ブランドのマークはブランドセットから取る。依存は一つにつきバージョンを一つ。Web の SVG の peer を渡し、node のエントリは両方とも導出する。法的主体は、サイトが述べる値にする。 |
| 8.27.1 | モデルピッカーは、自分の幅を自分で取る。 |
