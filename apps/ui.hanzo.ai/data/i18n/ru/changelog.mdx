---
title: Журнал изменений
description: Что изменил каждый релиз, по коммитам, которые его опубликовали.
---

Релизы выходят, когда версию пакета поднимают в `main`; каждая запись ниже — тема коммита, который это сделал.

## 8.27

| Версия | Изменение |
| --- | --- |
| 8.27.10 | Сорок один компонент перенесён на бэкенд gui. |
| 8.27.9 | Зазор сетки, названный токеном, всегда был 12px. `gap="$4"` на сетке теперь читает `var(--space-4)`, так что лестница в документе отвечает, и смена плотности двигает каждую сетку. |
| 8.27.8 | Документация каждого модуля рендерится из самого пакета. Каталог этого сайта читает barrel-файлы, цитирует типы каждого модуля и рендерит примеры рядом с исходником. |
| 8.27.7 | Box оставляет частям таблицы их табличные значения display. |
| 8.27.6 | Box несёт transition и text-overflow как стиль на пути тега. |
| 8.27.4 | Parts, Backdrop и Persona; backdrop, нарисованный позади разговора. |
| 8.27.3 | Кольцо вокруг всего composer, а не поля внутри него. |
| 8.27.2 | Версия называется один раз; знаки берутся из набора брендов; у каждой зависимости одна версия; поставляется веб-peer SVG и выводятся оба входа node; юридическое лицо становится значением, которое называет сайт. |
| 8.27.1 | Выбор модели берёт собственную ширину. |
