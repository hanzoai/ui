---
title: Сетка
description: Настоящая CSS-сетка, чьи дорожки задаёт контейнер, а не дети. Один проп на колонки и ни одного брейкпоинта.
---

Сетка, собранная руками, — каждый ребёнок на `width: calc(25% - 7.5px)`, — ровная лишь пока все дети согласны, а одно длинное слово делает ряд рваным. Подкручивание числа это не чинит. Здесь родитель объявляет дорожки один раз, и детям слова нет: равные колонки структурны, и ни один ребёнок не может расширить свою дорожку.

```tsx
import { Cell, Grid } from '@hanzo/ui/grid'
```

`Grid` лежит на собственном subpath, потому что рендерит `div` с `display: grid`, а ни того ни другого на React Native нет. API назван терминами CSS-сетки — `columns` и `rows` это списки дорожек, `Cell` ставит и растягивает, — поэтому нативный движок сетки меняет файл, а не места вызова.

## Колонки

`columns` принимает любую запись списка дорожек: число, список или записанный список дорожек.

```tsx
<Grid columns={3} gap="$3">
  <Tile>1</Tile>
  <Tile>2</Tile>
  <Tile>3</Tile>
</Grid>
```

<Preview>
  <Grid columns={3} gap="$3">
    <Tile>1</Tile>
    <Tile>2</Tile>
    <Tile>3</Tile>
  </Grid>
</Preview>

Число становится `repeat(3, minmax(0, 1fr))`, а не `1fr`, потому что одинокий `1fr` означает `minmax(auto, 1fr)`, а `auto` ставит пол дорожки по содержимому — неразрывная строка тогда раздвигает свою колонку. Это и есть рваный ряд, который компонент существует, чтобы не допустить, поэтому более длинная запись — суть.

```tsx
<Grid columns={['2fr', '1fr']} gap="$3">
  <Tile>main</Tile>
  <Tile>aside</Tile>
</Grid>
```

<Preview>
  <Grid columns={['2fr', '1fr']} gap="$3">
    <Tile>main</Tile>
    <Tile>aside</Tile>
  </Grid>
</Preview>

Число в списке — пиксели; всё остальное уже размер дорожки.

## Сколько поместится

Отзывчивая форма — это значение `columns`, а не второй проп, и брейкпоинта в ней нет. `min` — самая узкая ширина колонки, после которой сетка сбрасывает одну, а `max` ограничивает число.

```tsx
<Grid columns={{ min: 160, max: 4 }} gap="$3">
  <Tile>1</Tile>
  <Tile>2</Tile>
  <Tile>3</Tile>
  <Tile>4</Tile>
  <Tile>5</Tile>
  <Tile>6</Tile>
</Grid>
```

<Preview>
  <Grid columns={{ min: 160, max: 4 }} gap="$3">
    <Tile>1</Tile>
    <Tile>2</Tile>
    <Tile>3</Tile>
    <Tile>4</Tile>
    <Tile>5</Tile>
    <Tile>6</Tile>
  </Grid>
</Preview>

Измените размер окна: число следует за колонкой, в которой сидит сетка, поэтому тот же блок верен внутри сайдбара, которого он никогда не видел. `min` записан как `min(160px, 100%)`, а не голый `160px`, так что телефон уже пола получает одну дорожку на всю ширину, а не горизонтальную прокрутку. `max` складывается в тот же пол — одна M-я доля ряда, зазоры вычтены, — поэтому потолок на маленьком экране ничего не стоит.

## Ячейки

Обычному ребёнку обёртка не нужна. `Cell` существует, чтобы растянуться или встать на место: число занимает столько дорожек, строка — это `grid-column` как написано.

```tsx
<Grid columns={4} gap="$3">
  <Cell col={2}><Tile>col=2</Tile></Cell>
  <Tile>3</Tile>
  <Tile>4</Tile>
  <Cell col="1 / -1"><Tile>col="1 / -1"</Tile></Cell>
</Grid>
```

<Preview>
  <Grid columns={4} gap="$3">
    <Cell col={2}><Tile>col=2</Tile></Cell>
    <Tile>3</Tile>
    <Tile>4</Tile>
    <Cell col="1 / -1"><Tile>col="1 / -1"</Tile></Cell>
  </Grid>
</Preview>

`row` — то же самое вниз по странице. `rows` на сетке задаёт размер дорожек строк; без него строки сжимаются по содержимому.

## Зазор

`gap` — токен интервала или сырое число пикселей. Токен читает шкалу в документе — `gap="$4"` это `var(--space-4)`, — поэтому человек, который двигает плотность в панели внешнего вида, двигает вместе с ней каждую сетку. Число, разрешённое при рендере, фиксируется при рендере.

## Сам список дорожек

`tracks(columns, gap)` экспортируется, потому что это всё решение компонента: любая запись `columns` сводится к одному списку дорожек, который она означает, и обе инварианты выше сидят внутри.

```ts
import { tracks } from '@hanzo/ui/grid'

tracks(3)                       // 'repeat(3, minmax(0, 1fr))'
tracks({ min: 240 })            // 'repeat(auto-fill, minmax(min(240px, 100%), 1fr))'
```
