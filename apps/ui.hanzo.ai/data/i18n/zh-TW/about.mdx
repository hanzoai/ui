{brand.name} 是 {brand.org} 的元件庫。一個基底上的一個套件。有了這層基底，一次匯入才能在網頁上、在手機上、在桌面視窗裡跑起來。

## 組成

| 套件 | 它貢獻什麼 |
| --- | --- |
| [@hanzo/gui](https://gui.hanzo.ai) | 樣式引擎：樣式即 props，在網頁上編譯成原子 CSS，在手機上編譯成原生樣式，並帶上每種原語的行為——焦點、傳送、鍵盤。 |
| `@hanzo/design` | 權杖：單色調色盤、字級坡道、間距、圓角、高度、動效，以及每條坡道都要乘上的三枚旋鈕。 |
| `@hanzo/font` | Zen 與 Zen Mono，自行託管，遵循 SIL Open Font License。 |
| `@hanzo/appearance` | 一個人自己的讀法——字級、密度、強調色——存下來並套用。 |

元件是架在這四者之上的原創實作。底下沒有 Radix，沒有 Tailwind，沒有 class-variance-authority，也沒有登錄表。身份是普通的 CSS 自訂屬性，樣式表在套件釋出時，靠繪製每一個元件產生。
