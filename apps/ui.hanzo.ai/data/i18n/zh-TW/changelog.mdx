---
title: 變更紀錄
description: 每一次釋出改了什麼，取自把它送出去的那則提交。
---

釋出靠在 `main` 上抬升套件的版本來切；下面每一條都是做這件事的那則提交的標題。

## 8.27

| 版本 | 變更 |
| --- | --- |
| 8.27.10 | 把四十一個元件移植到 gui 後端。 |
| 8.27.9 | 用權杖寫下的格線 gap 一直是 12px。格線上的 `gap="$4"` 現在讀 `var(--space-4)`，文件裡的階梯會接住它，密度一變，每一張格線都跟著動。 |
| 8.27.8 | 每個模組的文件都從套件本身繪製出來。本站目錄讀取桶檔，引述每個模組的型別，並把範例畫在原始碼旁邊。 |
| 8.27.7 | Box 讓表格零件留在表格自己的 display 值上。 |
| 8.27.6 | Box 在標籤這條路上，把 transition 和 text-overflow 當作樣式帶上。 |
| 8.27.4 | Parts、Backdrop 和 Persona；塗在對話背後的一層背景。 |
| 8.27.3 | 環套住整個撰寫區，套的不是裡面那一個欄位。 |
| 8.27.2 | 版本只寫一次；品牌標記從一套品牌裡取；每個相依只給一個版本；補上網頁的 SVG peer，並導出兩份 node 入口；法律主體變成網站自己宣告的一個值。 |
| 8.27.1 | 模型選擇器自己佔自己的寬度。 |
