---
title: Änderungsprotokoll
description: Was jede Veröffentlichung geändert hat, aus den Commits, die sie veröffentlicht haben.
---

Veröffentlichungen werden geschnitten, indem die Paketversion auf `main`
angehoben wird; jeder Eintrag unten ist der Betreff des Commits, der das getan
hat.

## 8.27

| Version | Änderung |
| --- | --- |
| 8.27.10 | Portiert einundvierzig Komponenten auf das Gui-Backend. |
| 8.27.9 | Ein Grid-Abstand, der als Token benannt war, war immer 12px. `gap="$4"` auf einem Grid liest jetzt `var(--space-4)`, also antwortet die Leiter im Dokument, und eine Dichteänderung bewegt jedes Grid. |
| 8.27.8 | Rendert die Dokumentation jedes Moduls aus dem Paket selbst. Der Katalog dieser Site liest die Barrels, zitiert die Typen jedes Moduls und rendert seine Beispiele neben ihrem Quelltext. |
| 8.27.7 | Box lässt Tabellenteile auf ihren Tabellen-Display-Werten. |
| 8.27.6 | Box trägt transition und text-overflow als Style auf dem Tag-Pfad. |
| 8.27.4 | Parts, Backdrop und Persona; ein Backdrop, hinter das Gespräch gemalt. |
| 8.27.3 | Der Ring um den ganzen Composer, nicht um das Feld darin. |
| 8.27.2 | Eine Version einmal nennen; die Marken-Signets aus einem Markensatz nehmen; jeder Abhängigkeit eine Version geben; den Web-SVG-Peer liefern und beide Node-Einstiege ableiten; die juristische Person zu einem Wert machen, den die Site nennt. |
| 8.27.1 | Die Modellauswahl nimmt ihre eigene Breite. |
