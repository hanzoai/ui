{brand.name} ist die Komponentenbibliothek von {brand.org}. Es ist ein Paket
auf einem einzigen Unterbau, und der Unterbau ist der Grund, warum ein Import
auf dem Web, auf einem Telefon und in einem Desktop-Fenster läuft.

## Woraus sie besteht

| Paket | Was es beiträgt |
| --- | --- |
| [@hanzo/gui](https://gui.hanzo.ai) | Die Style-Engine: Styles als Props, auf dem Web zu atomarem CSS kompiliert und auf dem Telefon zu nativen Styles, mit dem Verhalten — Fokus, Portale, Tastatur — jedes Primitivs. |
| `@hanzo/design` | Die Tokens: die monochrome Palette, die Schriftrampe, der Abstand, der Radius, die Elevation, die Bewegung, und die drei Regler, mit denen sich jede Rampe multipliziert. |
| `@hanzo/font` | Zen und Zen Mono, selbst gehostet, unter der SIL Open Font License. |
| `@hanzo/appearance` | Die eigene Lesart einer Person vom System — Schriftgröße, Dichte, Akzent —, gespeichert und angewendet. |

Die Komponenten sind eine eigene Umsetzung auf diesen vieren. Kein Radix,
kein Tailwind, kein class-variance-authority und keine Registry darunter; die
Identität sind schlichte benutzerdefinierte CSS-Eigenschaften, und das
Stylesheet entsteht, indem beim Veröffentlichen des Pakets jede Komponente
gerendert wird.
