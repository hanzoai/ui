लाइब्रेरी में कुछ भी ब्रांड नहीं लेकर चलता। कंपोनेंट टोकन पढ़ता है, टोकन
कस्टम प्रॉपर्टी पढ़ता है, और प्रॉपर्टी वह है जो बिल्ड ने घोषित की। साइट,
चिह्न, नाम, रंग और चेहरा हर एक एक जगह एक मान है, इसलिए दूसरे संगठन का बिल्ड
इसके कुछ भी नहीं लेकर चलता।

## यह साइट

यह दस्तावेज़ `BRAND` एनवायरनमेंट चर से बनता है। `brand.ts` उसे एक बार पढ़ता
है और नाम, संगठन, इनलाइन SVG के रूप में चिह्न, उस चिह्न से निकला डेटा URI
के रूप में फ़ेविकॉन, कड़ियाँ, और जब ब्रांड के पास हो तो फ़्रेमवर्क की कड़ी
प्रकाशित करता है।

```bash
BRAND=lux pnpm build
```

पृष्ठ की हर स्ट्रिंग उस मॉड्यूल से आती है — हेडर, फ़ुटर, शीर्षक, और ये पृष्ठ
जो आप पढ़ रहे हैं, जो नाम की जगह `brand.name` लिखते हैं। कोड के नमूने उस
पैकेज के लिए फिर लिखे जाते हैं जिसका दस्तावेज़ बिल्ड बना रहा है, और कैटलॉग
वह मॉड्यूल या सदस्य गिरा देता है जो घर का नाम लेकर चलता हो जब बिल्ड दूसरे
ब्रांड का हो, ताकि दूसरे ब्रांड के `index.html` में इसका कोई निशान न रहे।

## पहचान

`@hanzo/ui/product/pure` वह ब्रांड सेट प्रकाशित करता है जिनसे चिह्न खींचे
जाते हैं — `HANZO`, `LUX`, `ZOO`, `PARS` — और `resolveBrand`, जो एक आईडी
का जवाब पहचान से देता है, घर पर वापस गिरते हुए।

```ts
import { BRANDS, resolveBrand, type BrandIdentity } from '@hanzo/ui/product/pure'

const brand: BrandIdentity = resolveBrand('lux')
brand.name     // 'Lux'
brand.viewBox  // '0 0 100 100'
brand.content  // the mark's inner SVG, drawn in currentColor
brand.href     // 'https://lux.network'
```

चिह्न `currentColor` इस्तेमाल करते हैं, इसलिए एक असेट दोनों थीम की सेवा
करता है; जो चिह्न अपनी भराई लेकर चलता है वह `fullColor` कहता है। उत्पाद
परत का एनिमेटेड लोगो पहचान को प्रॉप की तरह लेता है:

```tsx
import { AnimatedLogo } from '@hanzo/ui/product'
import { LUX } from '@hanzo/ui/product/pure'

<AnimatedLogo surface="Cloud" brand={LUX} />
```

## रंग और चेहरा

ब्रांड पहचान को कैस्केड में बाद में वही कस्टम प्रॉपर्टी घोषित करके फिर से
बिठाता है। उनमें से दो वे दिखावट की घुंडियाँ भी हैं जिन्हें व्यक्ति हिलाता
है, और सबसे संकरी राय अक्ष दर अक्ष जीतती है — पहले स्थापना, फिर संगठन, फिर
व्यक्ति।

```css
:root {
  --primary: #808000;
  --accent: #808000;
  --font-sans-provided: 'Inter', ui-sans-serif, system-ui, sans-serif;
}
```

`--font-sans` नहीं, `--font-sans-provided`: पैकेज का अपना बंधन एक कैस्केड
लेयर में बैठता है ताकि होस्ट की बिना लेयर की घोषणा अपनी विशिष्टता जो भी हो
जीत जाए, और यही होस्ट के चेहरे को वह बनाता है जो पेंट होता है।

`@hanzo/appearance` की संगठन परत वही घुंडियाँ सर्वर पर एक पंक्ति से लेकर
आती है। `current({ install, org, orgId })` सुलझाता है कि किसी संगठन में
किसी उपकरण पर व्यक्ति को क्या दिखना चाहिए, और `bootScript({ org, base })`
स्थापना और संगठन के डिफ़ॉल्ट हेड स्क्रिप्ट में पका देता है ताकि पहला पेंट
पहले से ब्रांड पर हो।

## जो रहता है

पैकेज अपना npm नाम रखता है, क्योंकि कोड नमूने का काम चिपकना है। वह नाम और
वह फ़्रेमवर्क जिस पर वह बना है, वे दो चीज़ें हैं जो दूसरे ब्रांड का बिल्ड
अब भी कहता है।
