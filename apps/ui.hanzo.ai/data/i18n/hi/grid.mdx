---
title: ग्रिड
description: असली CSS ग्रिड जिसकी पटरियाँ कंटेनर से आती हैं, बच्चों से नहीं। स्तंभों के लिए एक प्रॉप, और कोई ब्रेकपॉइंट नहीं।
---

हाथ से बिछाया ग्रिड — हर बच्चा `width: calc(25% - 7.5px)` पर — तभी सम रहता
है जब हर बच्चा सहमत हो, और एक लंबा शब्द पंक्ति को टेढ़ा कर देता है। संख्या
घिसने से वह नहीं सुधरता। यहाँ माता-पिता पटरियाँ एक बार घोषित करता है और
बच्चों की कोई राय नहीं: बराबर स्तंभ संरचना हैं, और कोई बच्चा अपनी पटरी
चौड़ा नहीं कर सकता।

```tsx
import { Cell, Grid } from '@hanzo/ui/grid'
```

`Grid` अपने सबपाथ पर है क्योंकि वह `display: grid` वाला `div` रेंडर करता
है, और दोनों React Native पर हैं ही नहीं। API CSS-ग्रिड की शब्दावली में
नाम रखती है — `columns` और `rows` पटरी सूचियाँ हैं, `Cell` रखता और फैलाता
है — इसलिए एक नेटिव ग्रिड इंजन फ़ाइल बदलता है, कॉल साइट नहीं।

## स्तंभ

`columns` पटरी सूची की कोई भी वर्तनी लेता है: एक गिनती, एक सूची, या लिखी
हुई पटरी सूची।

```tsx
<Grid columns={3} gap="$3">
  <Tile>1</Tile>
  <Tile>2</Tile>
  <Tile>3</Tile>
</Grid>
```

<Preview>
  <Grid columns={3} gap="$3">
    <Tile>1</Tile>
    <Tile>2</Tile>
    <Tile>3</Tile>
  </Grid>
</Preview>

गिनती `repeat(3, minmax(0, 1fr))` बनती है, `1fr` नहीं, क्योंकि अकेला `1fr`
का अर्थ `minmax(auto, 1fr)` है और `auto` पटरी को सामग्री पर रोकता है — एक
अटूट स्ट्रिंग फिर अपने स्तंभ को चौड़ा धकेलती है। वही टेढ़ी पंक्ति है जिसे
रोकने के लिए कंपोनेंट है, इसलिए लंबी वर्तनी ही बात है।

```tsx
<Grid columns={['2fr', '1fr']} gap="$3">
  <Tile>main</Tile>
  <Tile>aside</Tile>
</Grid>
```

<Preview>
  <Grid columns={['2fr', '1fr']} gap="$3">
    <Tile>main</Tile>
    <Tile>aside</Tile>
  </Grid>
</Preview>

सूची में संख्या पिक्सेल है; और कुछ पहले से पटरी का आकार है।

## जितने समाएँ

उत्तरदायी रूप `columns` का एक मान है, दूसरी प्रॉप नहीं, और उसमें कोई
ब्रेकपॉइंट नहीं। `min` वह सबसे कम चौड़ाई है जिसके बाद ग्रिड एक स्तंभ गिरा
देता है, और `max` गिनती को सीमित करता है।

```tsx
<Grid columns={{ min: 160, max: 4 }} gap="$3">
  <Tile>1</Tile>
  <Tile>2</Tile>
  <Tile>3</Tile>
  <Tile>4</Tile>
  <Tile>5</Tile>
  <Tile>6</Tile>
</Grid>
```

<Preview>
  <Grid columns={{ min: 160, max: 4 }} gap="$3">
    <Tile>1</Tile>
    <Tile>2</Tile>
    <Tile>3</Tile>
    <Tile>4</Tile>
    <Tile>5</Tile>
    <Tile>6</Tile>
  </Grid>
</Preview>

खिड़की का आकार बदलें: गिनती उस स्तंभ का अनुसरण करती है जिसमें ग्रिड है,
इसलिए वही ब्लॉक एक साइडबार के अंदर सही है जिसे उसने कभी नहीं देखा। `min`
नंगे `160px` की जगह `min(160px, 100%)` लिखा जाता है, ताकि फ़र्श से संकरी
फ़ोन को एक पूरी चौड़ाई की पटरी मिले, बगल की स्क्रॉल नहीं। `max` उसी फ़र्श
में सिमटता है — पंक्ति का एक Mवाँ हिस्सा, गैप घटाकर — इसलिए सीमा छोटी स्क्रीन
पर कुछ नहीं खर्च करती।

## सेल

सादे बच्चे को आवरण नहीं चाहिए। `Cell` फैलाने या रखने के लिए है: संख्या
उतनी पटरियाँ फैलाती है, स्ट्रिंग लिखी हुई `grid-column` है।

```tsx
<Grid columns={4} gap="$3">
  <Cell col={2}><Tile>col=2</Tile></Cell>
  <Tile>3</Tile>
  <Tile>4</Tile>
  <Cell col="1 / -1"><Tile>col="1 / -1"</Tile></Cell>
</Grid>
```

<Preview>
  <Grid columns={4} gap="$3">
    <Cell col={2}><Tile>col=2</Tile></Cell>
    <Tile>3</Tile>
    <Tile>4</Tile>
    <Cell col="1 / -1"><Tile>col="1 / -1"</Tile></Cell>
  </Grid>
</Preview>

`row` वही है, पृष्ठ के नीचे की ओर। ग्रिड पर `rows` पंक्ति की पटरियों का
आकार देता है; उसके बिना पंक्तियाँ सामग्री के अनुसार बनती हैं।

## गैप

`gap` एक अंतर-टोकन है या कच्चा पिक्सेल अंक। टोकन दस्तावेज़ की सीढ़ी पढ़ता
है — `gap="$4"` यानी `var(--space-4)` — इसलिए दिखावट पैनल में घनत्व हिलाने
वाला व्यक्ति हर ग्रिड को साथ हिलाता है। रेंडर पर सुलझा अंक रेंडर पर अटका
रहता है।

## पटरी सूची स्वयं

`tracks(columns, gap)` एक्सपोर्ट है, क्योंकि यही कंपोनेंट का पूरा निर्णय
है: `columns` की कोई भी वर्तनी उस एक पटरी सूची तक, जिसके अंदर ऊपर वाले दो
नियम हैं।

```ts
import { tracks } from '@hanzo/ui/grid'

tracks(3)                       // 'repeat(3, minmax(0, 1fr))'
tracks({ min: 240 })            // 'repeat(auto-fill, minmax(min(240px, 100%), 1fr))'
```
