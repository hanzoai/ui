{brand.name} {brand.org} की कंपोनेंट लाइब्रेरी है। हर कंपोनेंट
[@hanzo/gui](https://gui.hanzo.ai) से रेंडर होता है, React और React
Native का स्टाइल इंजन जो स्टाइल को प्रॉप मानकर वेब पर एटॉमिक CSS में
कंपाइल करता है। इंजन क्रॉस-प्लेटफ़ॉर्म है, इसलिए लाइब्रेरी भी: वही
`Switch` ब्राउज़र में `div` बनता है और फ़ोन पर नेटिव व्यू।

यहाँ यूटिलिटी-क्लास का बिल्ड नहीं है। न Tailwind, न PostCSS प्लगइन, न
किसी कंपोनेंट के नीचे Radix प्रिमिटिव, न रजिस्ट्री, न `components.json`,
और न कोई CLI जो स्रोत आपकी रिपॉज़िटरी में कॉपी करे। पैकेज स्थापित करें
और उसी से आयात करें।

## स्थापित करें और रेंडर करें

```bash
pnpm add @hanzo/ui @hanzo/gui
```

```tsx title="main.tsx"
import { Hanzo, Button } from '@hanzo/ui'

export default function App() {
  return (
    <Hanzo>
      <Button>Ship</Button>
    </Hanzo>
  )
}
```

इतनी ही तैयारी है। `Hanzo` रूट है, और तीन चीज़ें लेकर आता है जो पहले हर
ऐप का काम थीं: gui की कॉन्फ़िग जिसके विरुद्ध टोकन सुलझते हैं, स्टाइलशीट,
और थीम। आयात करने को कोई CSS नहीं और चलाने को कोई जनरेटर नहीं — शीट तब
बनती है जब पैकेज प्रकाशित होता है, हर कंपोनेंट को रेंडर करके और उस रेंडर
से निकला CSS बटोरकर, इसलिए पहला पेंट और हर सर्वर रेंडर अपने नियम पहले से
साथ लाते हैं।

होस्ट को अब भी अपने बंडलर को एक बात बतानी है, कि `react-native` का अर्थ
`react-native-web` है। एक एलियास, और [स्थापना](/docs/installation) के
नीचे हर होस्ट पृष्ठ बताता है कि वह कहाँ जाता है।

## स्टाइल प्रॉप है

स्टाइल कंपोनेंट पर एक प्रॉप है, और उत्तरदायी स्टाइल वही प्रॉप एक
ब्रेकपॉइंट कुंजी के नीचे।

```tsx
import { Button, Text, XStack, YStack } from '@hanzo/ui'

<YStack gap="$4" p="$5" $md={{ p: '$8' }}>
  <Text fontSize="$5" color="$color11">
    Balance
  </Text>
  <XStack gap="$2">
    <Button>Send</Button>
    <Button variant="outline">Receive</Button>
  </XStack>
</YStack>
```

ब्रेकपॉइंट मोबाइल-प्रथम न्यूनतम चौड़ाई हैं: `$sm` 640, `$md` 768,
`$lg` 1024, `$xl` 1280। `$` से शुरू होने वाला मान एक टोकन है — एक रंग,
एक आकार, अंतर की सीढ़ी का एक डंडा — और थीम के विरुद्ध सुलझता है, इसलिए
`$background` हल्के और गहरे में अलग रंग है, बिना कॉल साइट को पता चले।
फ़ॉन्ट का आकार हमेशा टोकन है, अंक कभी नहीं: `fontSize="$3"`, न कि
`fontSize={14}`। व्यक्ति अपनी टाइप स्केल रख सकता है और सीढ़ी `$n` उसके
साथ चलती है; लिख दिया गया 14 नहीं चल सकता। [थीम](/docs/theming) में
सीढ़ियाँ हैं।

## विन्यास

स्टैक फ्लेक्स हैं। `XStack` पंक्ति में रखता है, `YStack` स्तंभ में, और
दोनों `gap`, `items` और `justify` लेते हैं। ग्रिड असली CSS ग्रिड है,
`@hanzo/ui/grid` पर, जिसकी पटरियाँ कंटेनर से आती हैं, बच्चों से नहीं —
देखें [ग्रिड](/docs/grid)।

## क्या कहाँ है

| आयात | यह क्या है |
| --- | --- |
| `@hanzo/ui` | कंपोनेंट API — हर प्रिमिटिव, स्टैक, टाइप स्केल, और `Hanzo`। |
| `@hanzo/ui/product` | ऐप परत: चार्ट, पेज क्रोम, स्टेटस टैग, डिटेल पेन, थीम टॉगल। |
| `@hanzo/ui/blocks` | डेटा के रूप में सामग्री, और उसे खींचने वाले रेंडरर। |
| `@hanzo/ui/grid` | `Grid` और `Cell`, केवल वेब। |
| `@hanzo/ui/product/pure` | वे नियम जिन पर उत्पाद परत चलती है, बिना जुड़े कंपोनेंट के। |
| `@hanzo/ui/css` | `substitute`, उन परीक्षणों के लिए जिनका जवाब बिना कैस्केड का DOM नहीं दे सकता। |
| `@hanzo/ui/next` | Next का आवरण जो दोनों बंडलर के लिए वेब एलियास लगाता है। |

इस साइट के कैटलॉग पृष्ठ — [कंपोनेंट](/ui), [ब्लॉक](/blocks),
[उत्पाद](/product) — पैकेज से ही पढ़े जाते हैं: हर पृष्ठ एक मॉड्यूल के
उदाहरण उनके स्रोत के पास रेंडर करता है और उसके प्रकार उद्धृत करता है।

## सवाल

**क्या Tailwind चाहिए?** नहीं। कंपोनेंट स्टाइल प्रॉप लेते हैं, और पहचान
सादी CSS कस्टम प्रॉपर्टी है। अगर कोई ऐप क्लास की स्ट्रिंग लेकर आए, तो
`Box`, `sx` और `css` उन्हें `tw` से पढ़कर उन्हीं प्रॉप में बदल देते हैं;
DOM तक ऐसी कोई क्लास नहीं पहुँचती जिसे पैकेज ने परिभाषित न किया हो।

**क्या यह कॉपी करके चिपकाना है?** नहीं। पैकेज स्थापित करें और उसी से
आयात करें। कंपोनेंट पैकेज के साथ संस्करणित हैं, और एक्सपोर्ट मैप वह रास्ता
है जिससे सबपाथ सुलझता है, इसलिए गहरा आयात पैच के पार चलता रहता है।

**कौन से फ़्रेमवर्क?** कोई भी React 19 रेंडरर, जब बंडलर `react-native`
का एलियास जानता हो। पृष्ठ हैं [Vite](/docs/installation/vite),
[Next](/docs/installation/next), [One](/docs/installation/one),
[Expo](/docs/installation/expo) और [Tauri](/docs/installation/tauri) के।

**क्या व्यावसायिक उपयोग हो सकता है?** हाँ। Apache-2.0 या MIT, आपकी पसंद।
