---
title: Griglia
description: Una griglia CSS vera, le cui tracce vengono dal contenitore, non dai figli. Una prop per le colonne, e nessun breakpoint.
---

Una griglia fatta a mano — ogni figlio a `width: calc(25% - 7.5px)` — resta
pari solo finché ogni figlio è d'accordo, e una parola lunga lascia la riga
sfrangiata. Non si sistema regolando il numero. Qui il genitore dichiara le
tracce una volta e i figli non hanno voce: le colonne uguali sono una questione
di struttura, e nessun figlio può allargare la propria traccia.

```tsx
import { Cell, Grid } from '@hanzo/ui/grid'
```

`Grid` sta su un subpath proprio perché renderizza un `div` con
`display: grid`, e né l'uno né l'altro esiste in React Native. L'API è nominata
nei termini della griglia CSS — `columns` e `rows` sono liste di tracce,
`Cell` colloca e occupa — così un motore di griglia nativo cambia il file e
non i punti di chiamata.

## Colonne

`columns` accetta qualunque modo di scrivere una lista di tracce: un conteggio,
una lista, o una lista di tracce già scritta.

```tsx
<Grid columns={3} gap="$3">
  <Tile>1</Tile>
  <Tile>2</Tile>
  <Tile>3</Tile>
</Grid>
```

<Preview>
  <Grid columns={3} gap="$3">
    <Tile>1</Tile>
    <Tile>2</Tile>
    <Tile>3</Tile>
  </Grid>
</Preview>

Un conteggio diventa `repeat(3, minmax(0, 1fr))` e non `1fr`, perché `1fr` da
solo significa `minmax(auto, 1fr)` e `auto` appoggia il pavimento della traccia
sul contenuto: una stringa che non va a capo spinge allora la propria colonna
e la fa più larga. Quella è la riga sfrangiata che il componente esiste per
impedire, quindi la grafia lunga è lo scopo.

```tsx
<Grid columns={['2fr', '1fr']} gap="$3">
  <Tile>main</Tile>
  <Tile>aside</Tile>
</Grid>
```

<Preview>
  <Grid columns={['2fr', '1fr']} gap="$3">
    <Tile>main</Tile>
    <Tile>aside</Tile>
  </Grid>
</Preview>

Un numero dentro una lista sono pixel; tutto il resto è già una dimensione di
traccia.

## Quante ce ne stanno

La forma responsive è un valore di `columns`, non una seconda prop, e dentro
non c'è un breakpoint. `min` è la più stretta che una colonna può diventare
prima che la griglia ne lasci cadere una, e `max` mette un tetto al conteggio.

```tsx
<Grid columns={{ min: 160, max: 4 }} gap="$3">
  <Tile>1</Tile>
  <Tile>2</Tile>
  <Tile>3</Tile>
  <Tile>4</Tile>
  <Tile>5</Tile>
  <Tile>6</Tile>
</Grid>
```

<Preview>
  <Grid columns={{ min: 160, max: 4 }} gap="$3">
    <Tile>1</Tile>
    <Tile>2</Tile>
    <Tile>3</Tile>
    <Tile>4</Tile>
    <Tile>5</Tile>
    <Tile>6</Tile>
  </Grid>
</Preview>

Ridimensiona la finestra: il conteggio segue la colonna in cui sta la griglia,
così lo stesso blocco sta bene dentro una barra laterale che non ha mai visto.
`min` si scrive `min(160px, 100%)` e non un `160px` nudo, così un telefono più
stretto del pavimento ottiene una traccia a tutta larghezza invece di uno
scroll di lato. `max` si piega nello stesso pavimento — un M-esimo della riga,
tolti i gap — così il tetto non costa niente su uno schermo piccolo.

## Celle

Un figlio semplice non ha bisogno di un involucro. Una `Cell` esiste per
occupare o per collocarsi: un numero occupa tante tracce, una stringa è un
`grid-column` così come è scritto.

```tsx
<Grid columns={4} gap="$3">
  <Cell col={2}><Tile>col=2</Tile></Cell>
  <Tile>3</Tile>
  <Tile>4</Tile>
  <Cell col="1 / -1"><Tile>col="1 / -1"</Tile></Cell>
</Grid>
```

    <Tile>3</Tile>

    <Cell col="1 / -1"><Tile>col="1 / -1"</Tile></Cell>
  </Grid>

`row` è la stessa cosa scendendo nella pagina. `rows` sulla griglia dà
dimensione alle tracce di riga; senza, le righe si misurano sul contenuto.

## Distanza

`gap` è un token di spazio o un numero grezzo di pixel. Un token legge la
rampa nel documento — `gap="$4"` è `var(--space-4)` — così una persona che
muove la densità nel pannello dell'aspetto muove con sé ogni griglia. Un
numero risolto al render resta fisso in quel momento.

## La lista di tracce, quella vera

`tracks(columns, gap)` si esporta perché è tutta la decisione del componente:
qualunque modo di scrivere `columns`, verso l'unica lista di tracce che
significa, con dentro i due invarianti di sopra.

```ts
import { tracks } from '@hanzo/ui/grid'

tracks(3)                       // 'repeat(3, minmax(0, 1fr))'
tracks({ min: 240 })            // 'repeat(auto-fill, minmax(min(240px, 100%), 1fr))'
```
