---
title: Registro delle modifiche
description: Che cosa ha cambiato ogni versione, a partire dai commit che l'hanno pubblicata.
---

Le versioni si tagliano alzando la versione del pacchetto su `main`; ogni voce
qui sotto è l'oggetto del commit che l'ha fatto.

## 8.27

| Versione | Modifica |
| --- | --- |
| 8.27.10 | Porta quarantuno componenti sul backend di gui. |
| 8.27.9 | Una distanza di griglia nominata come token valeva sempre 12px. `gap="$4"` su una griglia ora legge `var(--space-4)`, così la scala nel documento risponde e un cambio di densità muove ogni griglia. |
| 8.27.8 | Renderizza la documentazione di ogni modulo dal pacchetto stesso. Il catalogo di questo sito legge i barrel, cita i tipi di ogni modulo e renderizza i suoi esempi accanto al sorgente. |
| 8.27.7 | Box tiene le parti di tabella sui loro valori di display da tabella. |
| 8.27.6 | Box porta transition e text-overflow come stile sul percorso del tag. |
| 8.27.4 | Parts, Backdrop e Persona; un backdrop dipinto dietro la conversazione. |
| 8.27.3 | L'anello circonda tutto il compositore, non il campo al suo interno. |
| 8.27.2 | Dichiara una versione una sola volta; prendi i segni del marchio da un insieme di marchi; dà a ogni dipendenza una sola versione; fornisci il peer SVG per il web e deriva entrambi gli ingressi di node; fai dell'entità legale un valore che il sito dichiara. |
| 8.27.1 | Il selettore del modello prende la propria larghezza. |
