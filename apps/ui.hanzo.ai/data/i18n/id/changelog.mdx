---
title: Catatan perubahan
description: Apa yang diubah tiap rilis, dari komit yang menerbitkannya.
---

Rilis dipotong dengan menaikkan versi paket di `main`; setiap entri di bawah adalah subjek komit yang melakukannya.

## 8.27

| Versi | Perubahan |
| --- | --- |
| 8.27.10 | Pindahkan empat puluh satu komponen ke backend gui. |
| 8.27.9 | Celah kisi yang dinamai sebagai token selalu 12px. `gap="$4"` pada kisi kini membaca `var(--space-4)`, jadi tangga di dokumen yang menjawab dan perubahan kerapatan menggeser setiap kisi. |
| 8.27.8 | Render dokumentasi setiap modul dari paket itu sendiri. Katalog situs ini membaca barrel, mengutip tipe tiap modul, dan merender contohnya di samping sumbernya. |
| 8.27.7 | Box mempertahankan bagian tabel pada nilai display tabel mereka. |
| 8.27.6 | Box membawa transition dan text-overflow sebagai gaya pada jalur tag. |
| 8.27.4 | Parts, Backdrop, dan Persona; sebuah backdrop yang dilukis di belakang percakapan. |
| 8.27.3 | Lingkari seluruh composer, bukan bidang di dalamnya. |
| 8.27.2 | Nyatakan versi sekali; ambil tanda merek dari satu set merek; beri setiap dependensi satu versi; sediakan peer SVG web dan turunkan kedua entri node; jadikan entitas hukum sebuah nilai yang dinyatakan situs. |
| 8.27.1 | Pemilih model mengambil lebarnya sendiri. |
