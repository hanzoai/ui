{brand.name} adalah pustaka komponen {brand.org}. Satu paket di atas satu
landasan, dan landasan itulah sebab satu impor berjalan di web, di telepon,
dan di jendela desktop.

## Tersusun dari

| Paket | Yang disumbangkannya |
| --- | --- |
| [@hanzo/gui](https://gui.hanzo.ai) | Mesin gaya: gaya sebagai prop, dikompilasi menjadi CSS atomik di web dan gaya native di telepon, dengan perilaku tiap primitif — fokus, portal, keyboard. |
| `@hanzo/design` | Token: palet monokrom, tangga huruf, jarak, radius, elevasi, gerak, dan tiga kenop yang mengalikan setiap tangga. |
| `@hanzo/font` | Zen dan Zen Mono, dihosting sendiri, di bawah SIL Open Font License. |
| `@hanzo/appearance` | Cara seseorang membaca sistem — ukuran huruf, kerapatan, aksen — disimpan dan diterapkan. |

Komponen adalah implementasi asli di atas keempatnya. Tidak ada Radix, tidak
ada Tailwind, tidak ada class-variance-authority, dan tidak ada registri di
bawahnya; identitasnya properti kustom CSS biasa, dan lembar gaya dihasilkan
dengan merender setiap komponen saat paket diterbitkan.
