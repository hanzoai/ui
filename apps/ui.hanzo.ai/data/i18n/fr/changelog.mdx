Les versions se coupent en montant la version du paquet sur `main` ; chaque
entrée ci-dessous est le sujet du commit qui l'a fait.

## 8.27

| Version | Changement |
| --- | --- |
| 8.27.10 | Porte quarante et un composants sur le backend gui. |
| 8.27.9 | Un écart de grille nommé comme token valait toujours 12px. `gap="$4"` sur une grille lit maintenant `var(--space-4)`, donc l'échelle du document répond et un changement de densité déplace chaque grille. |
| 8.27.8 | Rend la documentation de chaque module depuis le paquet lui-même. Le catalogue de ce site lit les barrels, cite les types de chaque module et rend ses exemples à côté de leur source. |
| 8.27.7 | Box garde les parties de tableau sur leurs valeurs de display de tableau. |
| 8.27.6 | Box porte transition et text-overflow comme style sur le chemin de la balise. |
| 8.27.4 | Parts, Backdrop et Persona ; un backdrop peint derrière la conversation. |
| 8.27.3 | L'anneau entoure tout le compositeur, pas le champ à l'intérieur. |
| 8.27.2 | Énonce une version une seule fois ; prend les signes de marque dans un jeu de marques ; donne à chaque dépendance une seule version ; fournit le peer SVG web et dérive les deux entrées node ; fait de l'entité légale une valeur que le site énonce. |
| 8.27.1 | Le sélecteur de modèle prend sa propre largeur. |
