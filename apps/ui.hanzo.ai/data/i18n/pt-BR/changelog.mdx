Os releases saem ao subir a versão do pacote na `main`; cada entrada abaixo é o assunto do commit que fez isso.

## 8.27

| Versão | Mudança |
| --- | --- |
| 8.27.10 | Leva quarenta e um componentes para o backend do gui. |
| 8.27.9 | Um gap de grade nomeado como token era sempre 12px. `gap="$4"` numa grade agora lê `var(--space-4)`, então a escada no documento responde e uma mudança de densidade move toda grade. |
| 8.27.8 | Renderiza a documentação de cada módulo a partir do próprio pacote. O catálogo deste site lê os barrels, cita os tipos de cada módulo e renderiza os exemplos ao lado do código-fonte. |
| 8.27.7 | O Box mantém as partes de tabela nos valores de display de tabela. |
| 8.27.6 | O Box carrega transition e text-overflow como estilo no caminho da tag. |
| 8.27.4 | Parts, Backdrop e Persona; um backdrop pintado atrás da conversa. |
| 8.27.3 | O anel contorna o composer inteiro, não o campo dentro dele. |
| 8.27.2 | Declare a versão uma só vez; tire as marcas de um conjunto de marcas; dê a cada dependência uma única versão; forneça o peer de SVG da web e derive as duas entradas de node; torne a entidade legal um valor que o site declara. |
| 8.27.1 | O seletor de modelo assume a própria largura. |
