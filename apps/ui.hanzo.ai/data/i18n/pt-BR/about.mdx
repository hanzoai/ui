{brand.name} é a biblioteca de componentes da {brand.org}. É um pacote sobre um único substrato, e o substrato é a razão de uma importação rodar na web, no telefone e numa janela de desktop.

## De que é feita

| Pacote | O que contribui |
| --- | --- |
| [@hanzo/gui](https://gui.hanzo.ai) | O motor de estilos: estilos como props, compilados em CSS atômico na web e em estilos nativos no telefone, com o comportamento — foco, portais, teclado — de cada primitivo. |
| `@hanzo/design` | Os tokens: a paleta monocromática, a rampa tipográfica, o espaçamento, o raio, a elevação, o movimento, e os três controles pelos quais cada rampa se multiplica. |
| `@hanzo/font` | Zen e Zen Mono, auto-hospedadas, sob a SIL Open Font License. |
| `@hanzo/appearance` | A leitura que uma pessoa faz do sistema — tamanho de tipo, densidade, acento — guardada e aplicada. |

Os componentes são uma implementação original sobre esses quatro. Não há Radix, nem Tailwind, nem class-variance-authority, nem um registro por baixo; a identidade são propriedades CSS personalizadas, e a folha de estilos é produzida renderizando cada componente quando o pacote é publicado.
