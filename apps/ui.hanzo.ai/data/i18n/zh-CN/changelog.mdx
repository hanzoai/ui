发布靠在 `main` 上抬升包的版本来切；下面每一条都是做这件事的那条提交的标题。

## 8.27

| 版本 | 变更 |
| --- | --- |
| 8.27.10 | 把四十一个组件迁到 gui 后端。 |
| 8.27.9 | 用令牌写下的网格 gap 一直是 12px。网格上的 `gap="$4"` 现在读 `var(--space-4)`，文档里的阶梯会接住它，密度一变，每一张网格都跟着动。 |
| 8.27.8 | 每个模块的文档都从包本身渲染出来。本站目录读取桶文件，引用每个模块的类型，并把示例画在源码旁边。 |
| 8.27.7 | Box 让表格零件留在表格自己的 display 值上。 |
| 8.27.6 | Box 在标签这条路上，把 transition 和 text-overflow 当作样式带上。 |
| 8.27.4 | Parts、Backdrop 和 Persona；画在对话背后的一层背景。 |
| 8.27.3 | 环套住整个编写区，套的不是里面那一个字段。 |
| 8.27.2 | 版本只写一次；品牌标记从一套品牌里取；每个依赖只给一个版本；补上 Web 的 SVG peer，并推导出两份 node 入口；法律主体变成站点自己声明的一个值。 |
| 8.27.1 | 模型选择器自己占自己的宽度。 |
