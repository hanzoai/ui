{brand.name} 是 {brand.org} 的组件库。一个基底上的一个包。正因为有这层基底，一次导入才能在 Web 上、在手机上、在桌面窗口里跑起来。

## 组成

| 包 | 它贡献什么 |
| --- | --- |
| [@hanzo/gui](https://gui.hanzo.ai) | 样式引擎：样式即 props，在 Web 上编译成原子 CSS，在手机上编译成原生样式，并带上每种原语的行为——焦点、传送、键盘。 |
| `@hanzo/design` | 令牌：单色调色板、字号坡道、间距、圆角、高度、动效，以及每条坡道都要乘上的三枚旋钮。 |
| `@hanzo/font` | Zen 与 Zen Mono，自行托管，遵循 SIL Open Font License。 |
| `@hanzo/appearance` | 一个人自己的读法——字号、密度、强调色——存下来并应用。 |

组件是架在这四者之上的原创实现。底下没有 Radix，没有 Tailwind，没有 class-variance-authority，也没有注册表。身份是普通的 CSS 自定义属性，样式表在包发布时通过渲染每一个组件生成。
