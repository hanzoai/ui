---
title: กริด
description: กริด CSS จริงที่รางมาจากกล่อง ไม่ใช่จากลูก พร็อพเดียวสำหรับคอลัมน์ และไม่มีจุดตัด
---

กริดที่จัดมือ — ทุกลูกที่ `width: calc(25% - 7.5px)` — เสมอก็ต่อเมื่อทุกลูกเห็นพ้อง และคำยาวคำเดียวทำให้แถวขาดรุ่ย ไม่มีอะไรแก้ได้ด้วยการจูนตัวเลข ที่นี่พ่อแม่ประกาศรางครั้งเดียว และลูกไม่มีสิทธิ์พูด คอลัมน์เท่ากันเป็นโครงสร้าง และไม่มีลูกทำให้รางของตัวเองกว้างได้

```tsx
import { Cell, Grid } from '@hanzo/ui/grid'
```

`Grid` อยู่ที่ซับพาธของตัวเองเพราะเรนเดอร์ `div` ด้วย `display: grid` และทั้งสองไม่มีบน React Native API ตั้งชื่อด้วยคำของกริด CSS — `columns` และ `rows` เป็นรายการราง `Cell` วางและทอด — ดังนั้นเอนจินกริดเนทีฟเปลี่ยนไฟล์ ไม่เปลี่ยนจุดเรียก

## คอลัมน์

`columns` รับการสะกดใดๆ ของรายการราง จำนวนนับ รายการ หรือรายการรางที่เขียนไว้

```tsx
<Grid columns={3} gap="$3">
  <Tile>1</Tile>
  <Tile>2</Tile>
  <Tile>3</Tile>
</Grid>
```

<Preview>
  <Grid columns={3} gap="$3">
    <Tile>1</Tile>
    <Tile>2</Tile>
    <Tile>3</Tile>
  </Grid>
</Preview>

จำนวนนับกลายเป็น `repeat(3, minmax(0, 1fr))` ไม่ใช่ `1fr` เพราะ `1fr` เดี่ยวหมายถึง `minmax(auto, 1fr)` และ `auto` ปูพื้นรางที่เนื้อหา สตริงที่ไม่ขาดแล้วดันคอลัมน์ของตัวเองให้กว้าง นั่นคือแถวขาดรุ่ยที่คอมโพเนนต์มีไว้ป้องกัน ดังนั้นการสะกดที่ยาวกว่าคือประเด็น

```tsx
<Grid columns={['2fr', '1fr']} gap="$3">
  <Tile>main</Tile>
  <Tile>aside</Tile>
</Grid>
```

<Preview>
  <Grid columns={['2fr', '1fr']} gap="$3">
    <Tile>main</Tile>
    <Tile>aside</Tile>
  </Grid>
</Preview>

ตัวเลขในรายการเป็นพิกเซล นอกนั้นเป็นขนาดรางอยู่แล้ว

## มากเท่าที่พอดี

รูปแบบที่ตอบสนองเป็นค่าของ `columns` ไม่ใช่พร็อพที่สอง และไม่มีจุดตัดในนั้น `min` คือแคบที่สุดที่คอลัมน์จะแคบได้ก่อนกริดทิ้งหนึ่งคอลัมน์ และ `max` จำกัดจำนวน

```tsx
<Grid columns={{ min: 160, max: 4 }} gap="$3">
  <Tile>1</Tile>
  <Tile>2</Tile>
  <Tile>3</Tile>
  <Tile>4</Tile>
  <Tile>5</Tile>
  <Tile>6</Tile>
</Grid>
```

<Preview>
  <Grid columns={{ min: 160, max: 4 }} gap="$3">
    <Tile>1</Tile>
    <Tile>2</Tile>
    <Tile>3</Tile>
    <Tile>4</Tile>
    <Tile>5</Tile>
    <Tile>6</Tile>
  </Grid>
</Preview>

ปรับขนาดหน้าต่าง จำนวนตามคอลัมน์ที่กริดอยู่ ดังนั้นบล็อกเดียวกันถูกต้องในแถบข้างที่มันไม่เคยเห็น `min` เขียนเป็น `min(160px, 100%)` ไม่ใช่ `160px` เปล่า ดังนั้นโทรศัพท์ที่แคบกว่าพื้นได้รางเต็มความกว้าง แทนการเลื่อนข้าง `max` พับเข้าพื้นเดียวกัน — หนึ่งใน M ของแถว หักช่องว่าง — ดังนั้นเพดานไม่กินอะไรบนจอเล็ก

## เซลล์

ลูกธรรมดาไม่ต้องมีตัวหุ้ม `Cell` มีไว้เพื่อทอดหรือเพื่อวาง ตัวเลขทอดรางเท่านั้น สตริงคือ `grid-column` ตามที่เขียน

```tsx
<Grid columns={4} gap="$3">
  <Cell col={2}><Tile>col=2</Tile></Cell>
  <Tile>3</Tile>
  <Tile>4</Tile>
  <Cell col="1 / -1"><Tile>col="1 / -1"</Tile></Cell>
</Grid>
```

<Preview>
  <Grid columns={4} gap="$3">
    <Cell col={2}><Tile>col=2</Tile></Cell>
    <Tile>3</Tile>
    <Tile>4</Tile>
    <Cell col="1 / -1"><Tile>col="1 / -1"</Tile></Cell>
  </Grid>
</Preview>

`row` ก็เช่นกัน ลงไปตามหน้า `rows` บนกริดกำหนดขนาดรางของแถว ไม่มีมันแถวขนาดตามเนื้อหา

## ช่องว่าง

`gap` เป็นโทเคนระยะหรือตัวเลขพิกเซลดิบ โทเคนอ่านบันไดในเอกสาร — `gap="$4"` คือ `var(--space-4)` — ดังนั้นคนที่ขยับความหนาแน่นในแผงรูปลักษณ์ขยับทุกกริดตาม ตัวเลขที่คลี่ตอนเรนเดอร์ตรึงตอนเรนเดอร์

## รายการรางเอง

`tracks(columns, gap)` ถูกส่งออก เพราะนั่นคือการตัดสินใจทั้งหมดของคอมโพเนนต์ การสะกดใดๆ ของ `columns` ไปยังรายการรางเดียวที่มันหมายถึง พร้อมสองกฎข้างบนอยู่ข้างใน

```ts
import { tracks } from '@hanzo/ui/grid'

tracks(3)                       // 'repeat(3, minmax(0, 1fr))'
tracks({ min: 240 })            // 'repeat(auto-fill, minmax(min(240px, 100%), 1fr))'
```
