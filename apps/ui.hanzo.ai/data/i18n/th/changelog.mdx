---
title: บันทึกการเปลี่ยนแปลง
description: แต่ละรุ่นเปลี่ยนอะไร จากคอมมิตที่เผยแพร่มัน
---

รุ่นถูกตัดโดยการเพิ่มเวอร์ชันแพ็กเกจบน `main` แต่ละรายการด้านล่างคือหัวข้อของคอมมิตที่ทำสิ่งนั้น

## 8.27

| เวอร์ชัน | การเปลี่ยนแปลง |
| --- | --- |
| 8.27.10 | ย้ายคอมโพเนนต์สี่สิบเอ็ดตัวไปยังแบ็กเอนด์ของ gui |
| 8.27.9 | ช่องว่างกริดที่ตั้งชื่อเป็นโทเคนเป็น 12px เสมอ `gap="$4"` บนกริดตอนนี้อ่าน `var(--space-4)` ดังนั้นบันไดในเอกสารเป็นฝ่ายตอบ และการเปลี่ยนความหนาแน่นจะเลื่อนทุกกริด |
| 8.27.8 | เรนเดอร์เอกสารของทุกโมดูลจากแพ็กเกจเอง แคตตาล็อกของไซต์นี้อ่านบาร์เรล อ้างชนิดของแต่ละโมดูล และเรนเดอร์ตัวอย่างข้างซอร์ส |
| 8.27.7 | Box คงส่วนของตารางไว้ที่ค่า display ของตาราง |
| 8.27.6 | Box ถือ transition และ text-overflow เป็นสไตล์บนเส้นทางแท็ก |
| 8.27.4 | Parts, Backdrop และ Persona พื้นหลังที่วาดไว้หลังบทสนทนา |
| 8.27.3 | ใส่วงรอบตัวเขียนทั้งหมด ไม่ใช่ช่องที่อยู่ข้างใน |
| 8.27.2 | ระบุเวอร์ชันครั้งเดียว หยิบเครื่องหมายแบรนด์จากชุดแบรนด์ ให้ทุกดีเพนเดนซีเวอร์ชันเดียว จัดเพียร์ SVG ของเว็บและอนุมานเอนทรี node ทั้งสอง ทำให้นิติบุคคลเป็นค่าที่ไซต์ระบุ |
| 8.27.1 | ตัวเลือกโมเดลใช้ความกว้างของตัวเอง |
