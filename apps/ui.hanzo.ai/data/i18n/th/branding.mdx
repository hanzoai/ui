ไม่มีอะไรในไลบรารีถือแบรนด์ คอมโพเนนต์อ่านโทเคน โทเคนอ่านคุณสมบัติกำหนดเอง และคุณสมบัติคืออะไรก็ตามที่บิลด์ประกาศ ไซต์ เครื่องหมาย ชื่อ สี และหน้าตัวอักษร แต่ละอย่างเป็นค่าเดียวในที่เดียว ดังนั้นบิลด์สำหรับองค์กรอื่นไม่ถืออะไรของอันนี้

## ไซต์นี้

เอกสารนี้สร้างจากตัวแปรสภาพแวดล้อม `BRAND` `brand.ts` อ่านมันครั้งเดียวแล้วเผยแพร่ชื่อ องค์กร เครื่องหมายเป็น SVG ในบรรทัด favicon เป็น URI ข้อมูลที่อนุมานจากเครื่องหมายนั้น ลิงก์ และลิงก์เฟรมเวิร์กเมื่อแบรนด์มี

```bash
BRAND=lux pnpm build
```

ทุกสตริงบนหน้ามาจากโมดูลนั้น หัว ท้าย ชื่อเรื่อง และหน้าที่คุณกำลังอ่าน ซึ่งเขียน `brand.name` แทนชื่อ ตัวอย่างโค้ดถูกเขียนใหม่เป็นแพ็กเกจที่บิลด์จัดทำเอกสาร และแคตตาล็อกทิ้งโมดูลหรือสมาชิกที่ถือชื่อบ้านออกจากบิลด์สำหรับแบรนด์อื่น ดังนั้น `index.html` ของแบรนด์อื่นไม่มีร่องรอยของอันนี้

## ตัวตน

`@hanzo/ui/product/pure` เผยแพร่ชุดแบรนด์ที่เครื่องหมายถูกวาดจากนั้น — `HANZO`, `LUX`, `ZOO`, `PARS` — และ `resolveBrand` ซึ่งตอบไอดีด้วยตัวตน และถอยกลับไปบ้าน

```ts
import { BRANDS, resolveBrand, type BrandIdentity } from '@hanzo/ui/product/pure'

const brand: BrandIdentity = resolveBrand('lux')
brand.name     // 'Lux'
brand.viewBox  // '0 0 100 100'
brand.content  // the mark's inner SVG, drawn in currentColor
brand.href     // 'https://lux.network'
```

เครื่องหมายใช้ `currentColor` ดังนั้นแอสเซ็ตเดียวรับใช้ทั้งสองธีม เครื่องหมายที่ถือสีเติมของตัวเองบอก `fullColor` โลโก้เคลื่อนไหวในชั้นผลิตภัณฑ์รับตัวตนเป็นพร็อพ

```tsx
import { AnimatedLogo } from '@hanzo/ui/product'
import { LUX } from '@hanzo/ui/product/pure'

<AnimatedLogo surface="Cloud" brand={LUX} />
```

## สีและหน้าตัวอักษร

แบรนด์ตั้งตัวตนใหม่ด้วยการประกาศคุณสมบัติกำหนดเองชื่อเดียวกันทีหลังในคาสเคด สองในนั้นเป็นปุ่มปรับรูปลักษณ์ที่คนขยับด้วย และความเห็นที่แคบที่สุดชนะทีละแกน ติดตั้ง แล้วองค์กร แล้วคน

```css
:root {
  --primary: #808000;
  --accent: #808000;
  --font-sans-provided: 'Inter', ui-sans-serif, system-ui, sans-serif;
}
```

`--font-sans-provided` ไม่ใช่ `--font-sans` การผูกของแพ็กเกจนั่งในเลเยอร์ของคาสเคด เพื่อให้การประกาศที่ไม่มีเลเยอร์จากโฮสต์ชนะไม่ว่าความจำเพาะจะเป็นเท่าใด และนั่นคือสิ่งที่ทำให้หน้าของโฮสต์เป็นหน้าที่ถูกเพนต์

ชั้นองค์กรของ `@hanzo/appearance` ถือปุ่มปรับเดียวกันจากแถวหนึ่งบนเซิร์ฟเวอร์ `current({ install, org, orgId })` คลี่ว่าคนในองค์กรบนอุปกรณ์ควรเห็นอะไร และ `bootScript({ org, base })` อบค่าเริ่มต้นของการติดตั้งและขององค์กรเข้าสคริปต์ในหัว เพื่อให้การเพนต์ครั้งแรกอยู่บนแบรนด์แล้ว

## สิ่งที่คงอยู่

แพ็กเกจคงชื่อ npm ของมัน เพราะงานของตัวอย่างโค้ดคือการถูกวาง ชื่อนั้นและเฟรมเวิร์กที่มันสร้างบนคือสองสิ่งที่บิลด์สำหรับแบรนด์อื่นยังพูด
