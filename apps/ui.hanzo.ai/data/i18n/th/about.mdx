{brand.name} คือไลบรารีคอมโพเนนต์ของ {brand.org} เป็นแพ็กเกจเดียวบนฐานเดียว
และฐานนั้นเองคือเหตุที่การนำเข้าครั้งเดียวรันบนเว็บ บนโทรศัพท์ และในหน้าต่างเดสก์ท็อป

## ประกอบด้วย

| แพ็กเกจ | ส่วนที่เติมให้ |
| --- | --- |
| [@hanzo/gui](https://gui.hanzo.ai) | เอนจินสไตล์ สไตล์เป็นพร็อพ คอมไพล์เป็น CSS แบบอะตอมบนเว็บ และเป็นสไตล์เนทีฟบนโทรศัพท์ พร้อมพฤติกรรมของแต่ละพื้นฐาน — โฟกัส พอร์ทัล คีย์บอร์ด |
| `@hanzo/design` | โทเคน จานสีเอกรงค์ บันไดตัวอักษร ระยะ รัศมี ระดับยก การเคลื่อน และปุ่มปรับสามตัวที่ทุกบันไดคูณด้วย |
| `@hanzo/font` | Zen และ Zen Mono โฮสต์เอง ภายใต้ SIL Open Font License |
| `@hanzo/appearance` | การอ่านระบบของแต่ละคน — ขนาดตัวอักษร ความหนาแน่น สีเน้น — ที่เก็บไว้และนำไปใช้ |

คอมโพเนนต์เป็นการทำให้เองบนสี่ส่วนนั้น ไม่มี Radix ไม่มี Tailwind ไม่มี class-variance-authority และไม่มีรีจิสทรีอยู่ข้างใต้ ตัวตนคือคุณสมบัติกำหนดเองของ CSS ธรรมดา และสไตล์ชีตเกิดจากการเรนเดอร์ทุกคอมโพเนนต์ตอนเผยแพร่แพ็กเกจ
