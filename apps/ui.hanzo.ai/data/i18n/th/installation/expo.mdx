ไลบรารีเรนเดอร์ผ่าน @hanzo/gui ซึ่งเป็น React Native ก่อน สแตกคือ `View` ข้อความคือ `Text` และพร็อพสไตล์คือสไตล์ ดังนั้นคอมโพเนนต์ชุดเดียวกับที่วาด `div` บนเว็บ ที่นี่วาดวิวเนทีฟ และโทเคนธีม บันไดระยะ กับบันไดตัวอักษรหมายถึงสิ่งเดียวกันทั้งสองที่

## ติดตั้ง

```bash
pnpm create expo-app@latest my-app
cd my-app
pnpm add @hanzo/ui @hanzo/gui
```

ไม่มีการตั้งค่าตัวรวมโมดูล นามแฝง `react-native` ที่โฮสต์เว็บตั้งคือสิ่งที่ทำให้ตัวรวมเว็บอ่านแพ็กเกจเนทีฟได้ Metro เป็นตัวรวมเนทีฟ และอ่านตามที่เขียน การนำเข้าสไตล์ชีตที่รูทถือไปไม่ทำอะไรใต้ Metro บนเนทีฟ และมีผลบน Expo เว็บ

## ติดตั้งรูท

```tsx title="app/_layout.tsx"
import { Hanzo } from '@hanzo/ui'
import { Stack } from 'expo-router'

export default function Layout() {
  return (
    <Hanzo>
      <Stack />
    </Hanzo>
  )
}
```

## สิ่งที่อยู่บนเว็บ

`@hanzo/ui/grid` เรนเดอร์ `div` ด้วย `display: grid` และทั้งสองไม่มีบน React Native — Yoga ไม่มีอัลกอริทึมกริด — จึงส่งที่ซับพาธของตัวเอง ไม่ใช่บนบาร์เรลของรูท จัดวางที่นั่นด้วย `XStack` และ `YStack` เอนจินกริดเนทีฟเปลี่ยนไฟล์นั้นไฟล์เดียว ไม่เปลี่ยนจุดเรียก แผนภูมิใน `@hanzo/ui/product` วาด SVG ในบรรทัดและวัดกล่องด้วย `ResizeObserver` ดังนั้นวันนี้พวกมันก็เป็นคอมโพเนนต์เว็บ

เป้าสัมผัสถึงพื้น 44 พอยต์ผ่าน `hitSlop` ไม่เคยผ่าน padding ดังนั้นกล่องของตัวควบคุมขนาดเท่ากันทั้งสองแพลตฟอร์ม และพื้นที่ที่แตะได้ไม่เท่า
