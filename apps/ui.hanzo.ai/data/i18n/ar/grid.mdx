description: شبكة CSS حقيقية، مساراتها من الحاوية لا من الأبناء. prop واحدة للأعمدة، وبلا نقاط انكسار.
---

الشبكة المصنوعة يدويًا — كل ابن على `width: calc(25% - 7.5px)` — لا تستوي إلا ما دام كل ابن يوافق، وكلمة طويلة تجعل الصف مشرشرًا. لا يُصلح ذلك ضبط الرقم. هنا يعلن الأب المسارات مرة واحدة وليس للأبناء قول: الأعمدة المتساوية بنيوية، ولا ابن يستطيع أن يوسّع مساره.

```tsx
import { Cell, Grid } from '@hanzo/ui/grid'
```

`Grid` في subpath خاص به لأنه يصيّر `div` بـ `display: grid`، ولا يوجد أي منهما على React Native. الواجهة مسمّاة بمصطلحات شبكة CSS — `columns` و`rows` قوائم مسارات، و`Cell` يضع ويمتد — فمحرّك شبكة أصلي يغيّر الملف لا مواضع الاستدعاء.

## الأعمدة

تأخذ `columns` أي هجاء لقائمة مسارات: عدًّا، أو قائمة، أو قائمة مسارات مكتوبة.

```tsx
<Grid columns={3} gap="$3">
  <Tile>1</Tile>
  <Tile>2</Tile>
  <Tile>3</Tile>
</Grid>
```

<Preview>
  <Grid columns={3} gap="$3">
    <Tile>1</Tile>
    <Tile>2</Tile>
    <Tile>3</Tile>
  </Grid>
</Preview>

يصير العدّ `repeat(3, minmax(0, 1fr))` لا `1fr`، لأن `1fr` وحده يعني `minmax(auto, 1fr)` و`auto` يجعل أرض المسار عند المحتوى — فسلسلة لا تنكسر تدفع عمودها أعرض. ذلك الصف المشرشر هو ما وُجد المكوّن لمنعه، فالهجاء الأطول هو المقصود.

```tsx
<Grid columns={['2fr', '1fr']} gap="$3">
  <Tile>main</Tile>
  <Tile>aside</Tile>
</Grid>
```

<Preview>
  <Grid columns={['2fr', '1fr']} gap="$3">
    <Tile>main</Tile>
    <Tile>aside</Tile>
  </Grid>
</Preview>

الرقم في قائمة هو بكسل؛ وأي شيء آخر مقاس مسار سلفًا.

## بقدر ما يتسع

الشكل المتجاوب قيمة لـ `columns`، لا prop ثانية، وليس فيه نقطة انكسار. `min` هو أضيق ما يبلغه عمود قبل أن تُسقط الشبكة واحدًا، و`max` يحدّ العدّ.

```tsx
<Grid columns={{ min: 160, max: 4 }} gap="$3">
  <Tile>1</Tile>
  <Tile>2</Tile>
  <Tile>3</Tile>
  <Tile>4</Tile>
  <Tile>5</Tile>
  <Tile>6</Tile>
</Grid>
```

<Preview>
  <Grid columns={{ min: 160, max: 4 }} gap="$3">
    <Tile>1</Tile>
    <Tile>2</Tile>
    <Tile>3</Tile>
    <Tile>4</Tile>
    <Tile>5</Tile>
    <Tile>6</Tile>
  </Grid>
</Preview>

غيّر مقاس النافذة: يتبع العدّ العمود الذي تقف فيه الشبكة، فتصح الكتلة نفسها داخل شريط جانبي لم تره قط. يُكتب `min` على أنه `min(160px, 100%)` لا `160px` عاريًا، فيأخذ هاتف أضيق من الأرضية مسارًا بعرض كامل بدل تمرير جانبي. ينطوي `max` في الأرضية نفسها — جزء من M من الصف، والفراغات مطروحة — فلا يكلّف السقف شيئًا على شاشة صغيرة.

## الخلايا

الابن العادي لا يحتاج إلى غلاف. `Cell` موجود ليمتد أو ليُوضع: الرقم يمتد بعدد من المسارات، والسلسلة `grid-column` كما كُتبت.

```tsx
<Grid columns={4} gap="$3">
  <Cell col={2}><Tile>col=2</Tile></Cell>
  <Tile>3</Tile>
  <Tile>4</Tile>
  <Cell col="1 / -1"><Tile>col="1 / -1"</Tile></Cell>
</Grid>
```

<Preview>
  <Grid columns={4} gap="$3">
    <Cell col={2}><Tile>col=2</Tile></Cell>
    <Tile>3</Tile>
    <Tile>4</Tile>
    <Cell col="1 / -1"><Tile>col="1 / -1"</Tile></Cell>
  </Grid>
</Preview>

`row` هو نفسه نزولًا في الصفحة. `rows` على الشبكة تحجّم مسارات الصفوف؛ ومن دونها تتحجّم الصفوف على المحتوى.

## الفراغ

`gap` رمز فراغ أو رقم بكسل خام. يقرأ الرمز التدرّج في المستند — `gap="$4"` هو `var(--space-4)` — فالشخص الذي يحرّك الكثافة في لوح المظهر يحرّك كل شبكة معه. والرقم الذي يُحل عند التصيير يثبت عند التصيير.

## قائمة المسارات نفسها

تُصدَّر `tracks(columns, gap)` لأنها قرار المكوّن كله: أي هجاء لـ `columns` إلى قائمة المسارات الواحدة التي يعنيها، والثابتان أعلاه داخلها.

```ts
import { tracks } from '@hanzo/ui/grid'

tracks(3)                       // 'repeat(3, minmax(0, 1fr))'
tracks({ min: 240 })            // 'repeat(auto-fill, minmax(min(240px, 100%), 1fr))'
```
