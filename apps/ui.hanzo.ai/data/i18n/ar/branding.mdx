لا تحمل المكتبة علامة. يقرأ المكوّن رمزًا، ويقرأ الرمز خاصية مخصصة، والخاصية هي ما أعلنه البناء. الموقع والشارة والاسم واللون والوجه كل واحد قيمة في موضع واحد، فبناء لمنظمة أخرى لا يحمل شيئًا من هذه.

## هذا الموقع

تُبنى هذه الوثائق من متغيّر البيئة `BRAND`. يقرأه `brand.ts` مرة واحدة وينشر الاسم، والمنظمة، والشارة على أنها SVG مضمّن، وأيقونة الموقع على أنها data URI مشتقة من تلك الشارة، والروابط، ورابط الإطار إن كان للعلامة واحد.

```bash
BRAND=lux pnpm build
```

كل سلسلة في الصفحة تأتي من تلك الوحدة — الترويسة، والتذييل، والعناوين، والصفحات التي تقرأها، وهي تكتب `brand.name` لا اسمًا. تُعاد كتابة عيّنات الشيفرة إلى الحزمة التي يوثّقها البناء، ويسقط الفهرس أي وحدة أو عضو يحمل اسم الدار من بناء لعلامة أخرى، فلا يحوي `index.html` الخاص بالعلامة الأخرى أثرًا من هذه.

## الهوية

ينشر `@hanzo/ui/product/pure` مجموعة العلامات التي تُرسم منها الشارات — `HANZO` و`LUX` و`ZOO` و`PARS` — و`resolveBrand`، الذي يجيب عن معرّف بالهوية ويرتد إلى الدار.

```ts
import { BRANDS, resolveBrand, type BrandIdentity } from '@hanzo/ui/product/pure'

const brand: BrandIdentity = resolveBrand('lux')
brand.name     // 'Lux'
brand.viewBox  // '0 0 100 100'
brand.content  // the mark's inner SVG, drawn in currentColor
brand.href     // 'https://lux.network'
```

تستخدم الشارات `currentColor`، فيخدم أصل واحد السمتين؛ والشارة التي تحمل تعبئاتها تقول `fullColor`. يأخذ الشعار المتحرّك في طبقة المنتج الهوية prop:

```tsx
import { AnimatedLogo } from '@hanzo/ui/product'
import { LUX } from '@hanzo/ui/product/pure'

<AnimatedLogo surface="Cloud" brand={LUX} />
```

## الألوان والوجه

تعيد العلامة ضبط الهوية بإعلان الخصائص المخصصة نفسها لاحقًا في التتالي. اثنتان منها هما أيضًا مقابض المظهر التي يحرّكها شخص، وأضيق رأي يفوز محورًا محورًا — التثبيت، ثم المنظمة، ثم الشخص.

```css
:root {
  --primary: #808000;
  --accent: #808000;
  --font-sans-provided: 'Inter', ui-sans-serif, system-ui, sans-serif;
}
```

`--font-sans-provided` لا `--font-sans`: ربط الحزمة نفسها يقعد في طبقة تتالٍ، فيفوز إعلان من المُضيف خارج الطبقة مهما كانت خصوصيته، وهذا ما يجعل وجه المُضيف هو الذي يُدهن.

تحمل طبقة المنظمة في `@hanzo/appearance` المقابض نفسها من صف على خادم. يحل `current({ install, org, orgId })` ما ينبغي أن يراه شخص في منظمة على جهاز، ويخبز `bootScript({ org, base })` افتراضيات التثبيت والمنظمة في نص الترويسة، فيكون أول رسم على العلامة سلفًا.

## ما يبقى

تُبقي الحزمة اسمها على npm، لأن عمل عيّنة الشيفرة أن تُلصق. ذلك الاسم والإطار الذي بُنيت عليه هما الشيئان اللذان ما زال بناء لعلامة أخرى يقوله.
