{brand.name} 은 {brand.org} 의 컴포넌트 라이브러리입니다. 하나의 기반 위에 놓인 하나의 패키지이고, 그 기반 때문에 하나의 임포트가 웹에서도, 휴대폰에서도, 데스크톱 창에서도 동작합니다.

## 구성

| 패키지 | 맡는 것 |
| --- | --- |
| [@hanzo/gui](https://gui.hanzo.ai) | 스타일 엔진. 스타일은 props 이고, 웹에서는 아토믹 CSS 로, 휴대폰에서는 네이티브 스타일로 컴파일됩니다. 각 프리미티브의 동작, 포커스, 포털, 키보드도 여기 있습니다. |
| `@hanzo/design` | 토큰. 모노크롬 팔레트, 타입 램프, 간격, 모서리, 높이, 움직임, 그리고 모든 램프가 곱하는 세 개의 노브. |
| `@hanzo/font` | Zen 과 Zen Mono. 직접 호스팅하고, SIL Open Font License 아래에 있습니다. |
| `@hanzo/appearance` | 그 사람 자신의 읽기. 글자 크기, 밀도, 액센트를 저장하고 적용합니다. |

컴포넌트는 이 네 가지 위의 독자적인 구현입니다. 밑에 Radix 도, Tailwind 도, class-variance-authority 도, 레지스트리도 없습니다. 정체는 평범한 CSS 커스텀 프로퍼티이고, 스타일시트는 패키지를 발행할 때 모든 컴포넌트를 렌더해서 만듭니다.
