릴리스는 `main` 에서 패키지 버전을 올려 자릅니다. 아래 각 항목은 그 커밋의 제목입니다.

## 8.27

| 버전 | 변경 |
| --- | --- |
| 8.27.10 | 마흔한 개의 컴포넌트를 gui 백엔드로 옮긴다. |
| 8.27.9 | 토큰으로 적은 그리드 gap 은 언제나 12px 였다. 그리드의 `gap="$4"` 는 이제 `var(--space-4)` 를 읽는다. 문서 안의 사다리가 답하고, 밀도를 바꾸면 모든 그리드가 움직인다. |
| 8.27.8 | 모듈마다의 문서를 패키지 자신에서 렌더한다. 이 사이트의 카탈로그는 배럴을 읽고, 각 모듈의 타입을 인용하며, 예제를 소스 옆에 그린다. |
| 8.27.7 | Box 는 표의 부품을 표의 display 값 그대로 둔다. |
| 8.27.6 | Box 는 태그 경로에서 transition 과 text-overflow 를 스타일로 싣는다. |
| 8.27.4 | Parts, Backdrop, Persona. 대화 뒤에 칠하는 배경. |
| 8.27.3 | 링은 안의 필드가 아니라 컴포저 전체에 두른다. |
| 8.27.2 | 버전은 한 번만 적는다. 브랜드 마크는 브랜드 세트에서 가져온다. 의존성마다 버전은 하나. 웹 SVG 피어를 넣고, node 엔트리는 둘 다 이끌어 낸다. 법적 주체는 사이트가 적는 값으로 둔다. |
| 8.27.1 | 모델 선택기가 자기 너비를 스스로 잡는다. |
