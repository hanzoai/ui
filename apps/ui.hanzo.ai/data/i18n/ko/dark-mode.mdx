---
title: 다크 모드
description: 다크가 먼저입니다. 라이트는 prop 하나. 어느 호스트에 있든 쓸 수 있는 토글.
---

정체의 기준은 다크입니다. `:root` 가 다크 팔레트를 지니고 `.light` 가 거기서 빠져나옵니다. 대부분의 스타일시트와는 반대이고, 일부러 그렇습니다. 루트를 마운트하고 달리 아무 말도 하지 않는 페이지는 브랜드의 바닥 위에 나옵니다. 흰색 위가 아닙니다.

## 정하는 것은 루트

```tsx
import { Hanzo } from '@hanzo/ui'

<Hanzo theme="light">{children}</Hanzo>
```

API 의 전부는 `theme` 입니다. 루트는 body 에 `.t_light` 또는 `.t_dark` 를 찍고, 모든 토큰은 그 테마에 대해 풀리며, 스타일시트의 커스텀 프로퍼티도 같은 클래스에 답합니다. 선택을 사람의 것으로 두고 싶은 호스트는 그것을 state 에 두고 루트에 넘깁니다.

## 토글

`@hanzo/ui/product` 의 `ThemeToggle` 은 버튼을 그리고 다음 테마를 알립니다. 제어되면 루트 옆의 한 줄입니다.

```tsx
import { useState } from 'react'
import { Hanzo } from '@hanzo/ui'
import { ThemeToggle, type ThemeMode } from '@hanzo/ui/product'

export function App({ children }) {
  const [theme, setTheme] = useState<ThemeMode>('dark')
  return (
    <Hanzo theme={theme}>
      <ThemeToggle theme={theme} onToggle={setTheme} />
      {children}
    </Hanzo>
  )
}
```

제어하지 않으면 `<ThemeToggle onThemeChange={fn} />` 이 문서 요소 자체의 `.dark` 와 `.light` 를 토글하고, 선택을 localStorage 의 `theme` 키 아래에 기억합니다. 넣어 둘 state 가 없는 호스트를 위한 것입니다. 어느 쪽이든 보여주는 것은 목적지입니다. 다크에서는 해, 라이트에서는 달입니다.

## Next

Next 호스트는 이미 `@hanzogui/next-theme` 를 돌리고 있고, 토글에서 그곳으로의 연결은 자기 서브패스에 있습니다. 다른 호스트가 프로덕트 층을 임포트하는 것만으로 Next 를 그래프에 끌어들이지 않게 하기 위해서입니다.

```tsx
import { ThemeToggleNext } from '@hanzo/ui/product/theme-toggle-next'

<ThemeToggleNext />
```

props 가 전혀 없는 `<ThemeToggle />` 은 동적 임포트로 같은 연결에 닿고, 그것이 없는 곳에서는 문서 토글로 돌아갑니다.

## One 과 Vite

이 사이트는 `@vxrn/color-scheme` 으로 선택을 지닙니다. 저장된 스킴을 첫 페인트 전에 정하고 루트에 알립니다.

```tsx
import { Hanzo } from '@hanzo/ui'
import { SchemeProvider, useUserScheme } from '@vxrn/color-scheme'

function Site({ children }) {
  const { value } = useUserScheme()
  return <Hanzo theme={value}>{children}</Hanzo>
}

export default function Layout({ children }) {
  return (
    <SchemeProvider defaultScheme="dark">
      <Site>{children}</Site>
    </SchemeProvider>
  )
}
```

`useUserScheme` 은 `setting` 도 내놓습니다. `system`, `dark`, `light` 중 하나입니다. 그리고 `set`. 이 사이트 헤더의 토글이 움직이는 것이 그것입니다.

## 번쩍이지 않게

어느 호스트에서든 테마 클래스는 스타일시트가 칠하기 전에 문서 위에 있어야 합니다. 그렇지 않으면 페이지는 다크로 칠했다가 라이트로 다시 칠합니다. Next 연결과 `@vxrn/color-scheme` 은 둘 다 인라인 스크립트에서 그것을 씁니다. 손으로 쓴 토글도 같아야 합니다. `html` 요소에 `suppressHydrationWarning` 을 두세요. 스크립트가 쓴 클래스는 React 가 렌더한 것이 아니기 때문입니다.
